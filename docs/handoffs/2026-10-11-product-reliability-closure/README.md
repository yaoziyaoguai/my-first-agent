## 1. 本轮目标

把现有 First Agent 收口为“单用户、本机、有人监督的日常代码/文件任务助手”：准备交付的代码能独立安装启动；用户输入不丢；纠正/暂停/恢复不滞留；验证对应最终代码；失败和收尾信息可信。

**不是从头造 Agent，不是开启新一轮能力扩张，也不是把所有历史 capability 重新晋级。** 保留现有架构，修复本轮审计确认的 13 项问题，补齐与这些修复直接相关的安装、生命周期和代表性任务证据。

用户批准的是准备本包。下一位执行者应在用户把本包作为执行任务交给它后实施；本包不自行授权后台启动其他 agent 或外部操作。

## 4. 架构和数据边界

- `AgentRuntime.run_turn` 保持唯一 production 模型/工具循环和状态变更入口。
- `ContextManager` 独占上下文选择；`ToolRuntime` 独占工具 callable 调用。
- CLI/TUI/headless 翻译 typed action、展示状态和 event，不自行执行工具、铸造证据或提交状态。
- Provider adapter 只做 ContextPack→ModelResponse。所有副作用保留审批、EXECUTING 和 result checkpoint。
- UNKNOWN 不自动重放，不把“操作员认为成功/失败”变成真实成功 receipt。
- 不降低路径、审批、网络、凭据、安全资源 owner 的约束来使测试通过。
- 优先用既有 fact/receipt/port 表达失效语义。若确需持久结构变化，先在 RESULTS 写清必要性、严格读写规则和重开测试；不得静默丢旧状态或用兼容 fallback 伪装成功。超出本包局部修复的迁移需另行批准。

## 5. 权限与实际 API

### 可在收到本包执行授权后直接做

公开源码的必要局部编辑、回归测试、独立临时 fixture、仅本次拥有的本地进程/专属浏览器/loopback 测试、manifest 清单管理及干净候选构建。默认按项目规则在当前 `main` 工作，不重置用户改动。

### 本包不授予

- commit/push/tag、合并远端分支、修改 remote、发布或部署。
- 读取历史私人会话/真实日志、根目录未跟踪 `tui/`、Memory/MCP/Skill/SubAgent 私有目录。
- 搜索全机密钥、访问个人浏览器 Profile、安装 macOS 登录项、启动 launchd/systemd 常驻或改系统安全策略。
- 无预算的付费调用或向外部模型发送整个私人工作区。

### 真实 Key 可以使用，但必须有明确的有效授权

不是禁止真实 API。Q3 要求真实模型证据，不允许以 mock 冒充。执行对话若已明确授权某个来源/环境变量、provider/model、任务数据范围和费用/次数上限，直接沿用有效授权，不重复询问。否则先完成全部无外部依赖工作，只在 Q3 前请求这些缺失授权。

用户曾为历史任务授权的预算不能自动继承；本包不包含任何真实 Key，也不让执行者从旧聊天抄 Key。只在 composition root 按指定环境变量或明确获准的文件注入。不得打印值、命令回显、写入资料包、源码、checkpoint、模型上下文或测试报告。不要使用过期会话里的 Key。

依赖缺失时优先已有隔离环境和本地缓存；若需联网安装，遵守执行宿主与用户的网络授权，只安装当前项目声明的必要依赖，记录版本，不全局升级开发环境。
